## Multilingual UI and contextual help
### v2.2.0 (2026-10-22)

Added multilingual UI, QA reports, and error guidance in five languages, with automatic language detection, English option labels, and localized tooltips.

### Language selection
- Support Korean, English, Japanese, Simplified Chinese, and Spanish without a translation API or network request.
- Default to Automatic on first launch, using the runtime's preferred languages; fall back to English when none is supported. This does not detect location, typed content, or the Figma menu language.
- Let users choose a language from the main UI or run report and restore that choice on subsequent launches.
- Preserve manual selection if saved preferences arrive late, and serialize saves to retain the most recent choice.

### Familiar labels, localized guidance
- Keep checkbox labels such as Colors, Spacing, Typography, Color Styles, and Text Styles in English, along with Variables, Collection, and Styles in section headings.
- Explain each option in the selected language through tooltips triggered by label hover or checkbox keyboard focus. Empty row space does not trigger tooltips; Escape dismisses them.
- Localize instructions, actions, progress, registration summaries, plugin-owned QA, and error guidance.
- Re-render existing reports and copied text when the language changes without resetting MD input or selected options.
- Preserve user-defined names, MD syntax, values, and original external error text. Unknown errors receive contextual guidance without guessing their cause.

### Maintenance and companion package
- Add a shared five-language catalog, placeholder validation, and a build step that embeds the runtime into the existing standalone plugin files.
- Keep the MD format compatible with v2.1.0. Downloaded templates, AI guides, and Figma Agent skill instructions retain their existing content.
- Publish companion package v0.1.2 with the parser's structured error helpers included, so malformed MD produces useful validation errors rather than missing-helper errors.

### Validation
- 23 automated checks cover import/export regressions, language detection and persistence, structured errors, catalog parity, and companion packaging.
- Browser checks cover all five languages at 500px and 390px, localized tooltips, keyboard access, report copying, input preservation, and safe rendering of user text.
- The publisher confirmed the UI behavior in Figma and published the Figma Community update before this GitHub release.
