# 🚀 MD to Figma: Global AI Prompt Guide

Register your entire design system into Figma Variables & Styles in seconds. This guide helps you bridge the gap between your documentation and Figma using the power of AI.

---

## 📋 The Workflow (작업 순서)

### 1. Download the Template (템플릿 다운로드)
- Click **📥 Template Download** in the plugin to get `DESIGN-TEMPLATE.md`.
- 이 파일은 플러그인이 인식할 수 있는 유일한 데이터 구조를 정의합니다.

### 2. Instruct Your AI (AI에게 작업 요청)
- Attach the `DESIGN-TEMPLATE.md` file to your AI (ChatGPT, Claude, Gemini, etc.).
- Provide your project's raw design data (CSS, JSON, or doc text).
- Use the **Master Prompt** provided below.

### 3. Generate & Sync (생성 및 동기화)
- Copy the Markdown code block generated by the AI.
- Paste it into the **MD to Figma** plugin and click **🚀 Generate**.
- 피그마 배리어블과 스타일이 자동으로 생성됩니다.

---

## 🤖 The Master Prompt (복사하여 사용하세요)

> "I have attached a `DESIGN-TEMPLATE.md` file that defines a specific structure for a Figma plugin. 
> 
> Please analyze my project's design system data provided below and **restructure it exactly** into the format defined in the template. 
> 
> **CRITICAL COMPLIANCE RULES:**
> 1. **Color Aliasing**: In the 'Semantic' table, values MUST reference names from the 'Primitive' table (e.g., `blue/500`). **Never use HEX codes in Semantic tables.**
> 2. **Typography Grouping**: Use `### Heading` syntax to group typography tokens (e.g., `### Display`).
> 3. **Value Formatting**: All numbers must have units (e.g., `16px`, `1.5`, `120%`).
> 4. **Dark Mode Inference**: If I don't provide dark mode values, please infer appropriate dark mode colors based on the 'Dark Mode Inference Guide' inside the template's comments.
> 
> Output the result as a single, complete Markdown code block."

---

## 💡 Pro Tips for Success
- **Batch Processing**: The plugin supports partial updates. You can sync Colors first, then Spacing later.
- **Natural Sorting**: Token names like `gray/100`, `gray/200` are automatically sorted numerically in Figma.
- **Refinement**: If the AI makes a mistake, just say: *"Follow the alias rule for semantic colors and try again."*
